# MT5 黄金交易工作台

基于 PySide6 6.11.2 与 Qt Quick/QML 的本地 Python 图形界面，读取当前已登录的 MetaTrader 5 账户、
`XAUUSDc` 报价、持仓和挂单，并测算固定止损下的限价单分档方案。工作台分为
“总览看板”“交易概览”“行情日志”“下单管理”“控制面板”“指标参考”“实验功能”“系统配置”八页；首页提供 M5 K 线、账户关键指标和
近 30 日已实现净损益。测算后可在预览窗口确认并发送 LIMIT 挂单。

## 启动

在 Windows PowerShell 中运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m mt5_workbench
```

界面使用项目依赖清单中固定版本的 PySide6；启动和安装依赖均使用该虚拟环境中的 Python。
新界面使用 Qt Quick 原生渲染和 FluentWinUI3 控件样式，不嵌入 HTML 或 WebEngine。
原有的 `.\.venv\Scripts\python.exe .\gui.py` 启动命令暂时保留为兼容入口。
如有多个 MT5 客户端，可加 `--terminal "C:\Program Files\MetaTrader 5\terminal64.exe"`。
工作台只接受账户币种为 `USC` 的美分账户，并按 **100 USC = 1 USD** 计算。
连接时和运行中都会重新读取 MT5 账户；若币种不是 `USC`，工作台会弹出锁定警告，
停止看板读取、仓位测算和交易操作。切换回 `USC` 账户后，点击顶部“重新连接”。
界面有日间、夜间两种主题；首次启动随 Windows 应用主题，之后记住右上角切换的选择。
侧栏固定为八个工作区，当前仅面向 `XAUUSDc`，不提供切换交易品种的入口。
最小窗口为 **1200 × 800**，页面在窗口化时可纵向滚动；支持全屏与 2K 显示，
可点击右上角“全屏”或按 `F11`，按 `Esc` 退出。界面规则见 [界面设计规范](docs/UI_DESIGN.md)。
侧栏和操作按钮使用统一图标；深浅主题自动切换对应配色。图表由 Qt Quick 绘制，
无需额外安装网页浏览器组件。
图标的 SVG 源文件与多尺寸 PNG 位于 [界面资源目录](src/mt5_workbench/ui/resources/icons/README.md)。

## 工程目录

桌面应用代码位于 `src/mt5_workbench/`，按职责划分：

| 目录 | 内容 |

| `ui/qml_bridge.py` | 只读账户状态、行情、历史数据后台读取与 QML 状态同步 |

| `ui/pages/`、`ui/main_window.py` | 保留的 QWidget 旧版界面实现，非默认入口 |

`tests/` 是离线测试；`docs/` 保存架构说明。项目根目录只保留元数据、资源和兼容启动脚本。
代码分层和后续整理阶段见 [架构计划](docs/ARCHITECTURE_PLAN.md)。

## 系统配置

侧栏“系统配置”集中管理工作台的全局设置，未连接 MT5 或账户受限时仍可打开。
当前系统时间、UTC 时间与所选时区的显示时间每秒更新；显示时区默认北京时间
（UTC+8），可选择跟随系统时区、UTC，或 UTC−12 至 UTC+14 的整点偏移。
报价、K 线、订单时间、行情监听和日志时间轴立即同步，重启后保留所选时区。
切换时区只改变显示；按日盈亏与账户曲线保留原统计口径，日志热力图和活跃天数仍按北京时间计算。

该页也可修改报价、持仓、订单刷新间隔，与底栏设置同步；主题与顶栏同步，
全屏模式仅用于当前会话。时区保存在 `state/system_settings.json`，刷新间隔及主题
继续使用现有偏好文件。配置与文本文件统一使用 UTF-8；页面展示系统默认编码、
Python UTF-8 模式、运行环境、MT5 客户端路径以及可复制的本地数据和日志目录。
这些环境信息与固定品种、USC 账户规则为只读信息。

## 总览看板

首页从 MT5 读取 `XAUUSDc` 实时报价、昨日收盘价和最近 72 根 M5 K 线，
展示 Bid/Ask、点差、较昨收变动、账户净值、余额、浮动盈亏、可用保证金、
保证金水平以及当前持仓和挂单。底栏的“报价／持仓／订单”时间可点击编辑，
分别控制实时报价、总览持仓及总览挂单／交易概览的自动读取；默认 1、5、30 秒，
可设 1–3600 秒，重启后保留。账户安全检查仍每秒执行，图表与历史统计每 60 秒刷新。

近 30 日柱状图统计**已实现净损益**，单位始终是账户币种（本账户为 USC），
包含交易成交的利润、佣金、隔夜费及手续费；不含当前浮动盈亏和出入金。
历史读取失败会显示不可用，不会把缺失数据当作零。K 线包含正在形成的当前一根，
用空心柱区分；图表时间轴使用系统配置的显示时区，默认北京时间（UTC+8）。

## 交易概览

左侧“交易概览”是只读看板，分别读取 MT5 的当前挂单、当前持仓、历史订单和
实际成交。可切换 `XAUUSDc` 与整个账户，以及近 7 / 30 / 90 个本地日；
页面可见时按底栏“订单”间隔刷新（默认 30 秒），也可手动刷新。切换账户时会清空上一个账户的记录。
历史读取在后台进行，首次进入可立即切页；账户或筛选条件变化时会丢弃过期结果。

顶部展示当前余额、当前净值，以及所选期间**全账户**的累计交易净现金流折线。
鼠标悬浮到日期可查看当日净额、累计净额和回撤。最大回撤与当前距峰值按每日
累计现金流计算，单位为账户币种；期间起点设为零。这条曲线排除出入金和
未平仓浮盈亏，**不是历史余额或权益曲线**，其回撤也不是 MT5 内置报告的
账户权益回撤。选择 `XAUUSDc` 只影响下面的订单/成交明细与相关指标，
账户曲线始终统计整个账户。

看板显示挂单数、持仓数、期间历史订单数、实际成交笔数、交易净现金流与挂单
止损覆盖情况。每日成交图按 BUY / SELL **成交方向**展示；全账户视图改用
成交笔数，避免把不同品种的手数相加。历史订单状态图只统计已结束的历史订单。
三个明细表分别列出当前有效挂单、最近 100 笔 BUY / SELL 实际成交及最近
100 笔历史订单；选中一行可查看时间、价格、止损止盈或成交资金分项。
顶部统计仍覆盖所选期间的全部返回记录，不受明细表 100 行上限影响。

金额直接使用账户币种（本账户为 USC，**100 USC = 1 USD**）。
“交易净现金流”汇总成交利润、隔夜费、佣金和手续费，并纳入能够关联的独立
佣金分录；它不等同于已完整平仓交易的盈亏，逐笔成交现金流也不应当作一笔
完整交易的利润。BUY / SELL 成交方向也不等同于当前持仓方向。MT5 某类历史
读取失败时，该类指标显示“—”和错误信息，不把缺失记录算作零。
此页不会调用 `order_send()`。

[MT5 Python 接口](https://www.mql5.com/en/docs/python_metatrader5)提供原始订单与成交记录，
但没有直接返回终端内置交易报告的函数。终端可[手动导出 HTML/PDF 报告](https://www.metatrader5.com/zh/terminal/help/trading_advanced/history_report)；
本页为保证自动更新，直接依据成交记录计算。

## 指标参考：ATR 与平均日波动

“指标参考”展示年、月、周、日 **ATR(14)**，周期可设为 1–100。采用
[MetaQuotes ATR](https://www.mql5.com/en/code/12) 的简单平均口径：
`TR = max(最高 − 最低, |最高 − 前收|, |最低 − 前收|)`，ATR 为最近 N 根 TR 的平均值。
只读取已收盘 K 线，年线由 12 根连续月线合成；年 ATR(14) 需要 15 个完整年份，
历史不足或读取失败时显示“—”及原因，不以零或较短周期替代。

下方按近一年、近一个月、近一周及最近交易日展示平均**日线真实波幅**。
区间以最后一个已收盘交易日为终点，按 UTC K 线日期取日历区间；平均值只除以实际
交易日数，最近交易日显示单日 TR。历史未覆盖完整区间时不给出区间平均值。
所有波动数值直接展示价格幅度，例如价格从 4200 到 4205，波动为 5。

可输入每日目标价格幅度，查看其占所选区间平均日波幅的比例。
ATR 是行情波动参考，不是每日可赚利润；实际收益还取决于手数、进出场和交易成本。
页面可见时每 60 秒后台刷新，也可手动刷新；切换账户或断线会清空指标。

## 实验功能：行情监听

侧栏最后一页只读监听 `XAUUSDc` 的 M1 EMA 7、14、30、60。页面可见时按底栏“报价”
间隔（默认**约每秒**）读取最新报价及 200 根 M1 K 线；显示四条 EMA、最新 Bid/Ask、
报价年龄和四条 EMA 的最大差距。当前形成中的 M1 K 线会随新报价变化。

“聚拢候选”表示 `最高 EMA − 最低 EMA ≤ 品种 point × 允许差距`，允许差距默认
**5 point**，可在页面调整。至少需要 180 根有效 M1 K 线；若报价超过 15 秒未更新、
当前分钟 K 线缺失或连接中断，不会给出聚拢候选。会话内的候选记录只保留最近
12 条，切换账户或断线会清空，不写入本地数据库。聚拢只是描述均线接近，
**不能据此推断价格很可能反转**；该实验页不会自动下单。

默认 1 秒是程序配置的轮询间隔，并非 MT5 Python 接口公布的最高刷新速率，
也不保证每次都能获得新 tick。历史数据、控制目标和图表读取在后台执行，
短时 MT5 连接检查或行情读取仍可能延后定时器回调；
若要测量本机可持续极限速率，需要在交易时段做只读基准测试。

在项目根目录的 PowerShell 中运行 `powershell -ExecutionPolicy Bypass -File .\build.ps1`。
脚本会安装 `requirements.txt` 和 `requirements-build.txt` 中的依赖，生成
单文件 `dist/MT5Workbench.exe`，以及包含 EXE 和使用说明的
`dist/MT5Workbench-Windows-x64.zip`、校验文件 `dist/SHA256SUMS.txt`。
可直接双击 EXE，或解压 ZIP 后运行；
Python、MetaTrader5 Python 包、NumPy 和 PySide6 图形界面运行库均已包含在包内。
仍需在目标电脑安装并登录 MetaTrader 5 客户端。请保留程序旁的 `state/` 目录，
其中存有交易执行记录、行情日志和界面主题偏好。完整使用说明见压缩包内的 `README-package.txt`。

EXE 包含运行依赖，第一次启动会在系统临时目录解包，因此比源码启动稍慢。
用户数据仍保存在 **EXE 旁的 `state/`**，不会保存在临时解包目录。
发布包不包含个人数据。从源码版切换时，将 EXE 放到项目根目录，与原有 `state/`
并列即可沿用日志和设置；或将 EXE 和完整 `state/` 一起复制到新目录。

## 下单管理（限价单）

下单管理分为 **基础下单** 与 **高级下单** 两个 Tab，默认打开基础下单，两种模式仅发送
BUY LIMIT 或 SELL LIMIT。切换 Tab 会取消之前的发送确认，高级模式需重新计算。

### 基础下单

选择买入限价或卖出限价，填写价格与手数（默认 **0.5 手**），必须填写止损，止盈可选。
基础模式直接使用指定手数，不应用高级模式的预算比例或自动分仓。价格、止盈、止损默认留空；未设置有效止损不能预览或发送限价单。
点击“预览买入限价单”或“预览卖出限价单”，核对账户、价格、手数、保护价及估算风险，
再点击“确认发送”提交一笔挂单。预览与发送时均强制校验止损，通过
MT5 的 `order_calc_profit()` 计算 USC 风险并换算为 USD。

预览与确认时均核对账户、交易权限、最新报价、价格和手数步进、挂单及保护价方向，
并通过 `order_check()` 检查；沿用重复挂单拦截、单次确认及本地发送记录。
修改字段、切换模式或账户会使原确认失效。

### 高级下单

风险预算、目标入场价、误差度和统一止损价初始为空，需要自行填写；预算使用比例默认
**95%**、开仓档数默认 **3**、加权模式的每档权重默认 `1,2,3`。
统一止盈价可选：留空表示不设置止盈，填写后所有档位使用同一止盈价。

输入目标价 **4220**、误差度 **1**，程序自动生成 **4219～4221** 的入场区间；
三档时价格为 **4219、4220、4221**。止损必须在整个区间之外。

填写示例：风险预算 **30 USD**、预算使用比例 **95%**，因此实际风险上限为
**28.50 USD**；目标价 **4205**、误差度 **5**，生成区间 **4200～4210**，统一止损 **4220**，
三档等距价格 **4200、4205、4210**。止损在区间上方时按 SELL 测算，
在区间下方时按 BUY 测算。支持四种模式：

- **加权分配**：输入 `1,2,3` 等权重，按比例分配每档的美元风险。
- **等风险**：每档承担近似相同的美元风险。
- **覆盖区间、总手数优先**：每档至少有券商最小手数，剩余预算优先放到离止损最近的价格。
- **单点总手数最大**：仅在离止损最近的区间端点配置手数。

示例按 `1,2,3` 加权，当前合约参数下约为 **0.23 / 0.64 / 1.43 手**，
合计 **2.30 手**，三档都成交并触及止损时估算风险 **28.50 USD**，
相对原预算保留 **1.50 USD**。
各档手数会按 MT5 的最小手数、步进与最大手数约束处理。

“预算使用比例”与“每档风险权重”不同：前者先决定整次测算可使用的上限
（`风险预算 × 百分比`，允许 0～100% 中大于 0 的数）；后者只在加权模式中
分配这个上限。四种模式的结果都会遵守相同的有效上限。界面“原预算剩余”
显示原始预算减去估算风险，包含预留比例与手数步进留下的余额。

风险约定为 `1 手 × 价格波动 1 = 1 USD`。当前账户币种是 USC，
按 `100 USC = 1 USD` 换算；计算时也会调用 MT5 的 `order_calc_profit()` 核对。
如果合约实际风险与约定明显不符，会拒绝给出配置。

计算结果只表示**所有列出的档位都成交，随后在指定价格止损**时的估算亏损。
滑点、跳空、手续费、隔夜费和保证金限制未计入；界面只提示 LIMIT 候选或不可作为 LIMIT，
当前报价不满足 LIMIT 条件时禁用发送预览。
可用“复制配置”将结果复制到剪贴板。

## 发送 LIMIT 挂单

计算结果后点击“预览 LIMIT 挂单”。程序重新读取账户、品种和报价，核对当前测算结果、
预算上限、止盈方向、价格步进、最小手数、最小挂单距离及现有相同挂单；仅当所有档位均可作为
BUY LIMIT 或 SELL LIMIT，且全部通过 MT5 `order_check()` 时才会显示发送预览。
预览列出账户、生成区间、实时报价、每笔入场价、手数、统一止损、统一止盈和估算风险。核对后点击
“确认发送”才会逐笔调用 `order_send()`；点击“取消”则关闭预览且不发送。
挂单使用 GTC（长期有效）。填写止盈价时，程序会核对其方向、品种支持情况和最小距离，
并将它写入每笔挂单；留空则在预览中显示“—”。
真实发送前须在 MT5 客户端启用“算法交易”；未启用时界面会阻止发送。

程序在发送前建立本地记录，逐笔保存返回的订单号与状态到 `state/executions/`，
同一配置重复发送会被阻止。若中途失败或返回状态不确定，程序停止后续挂单，
不会自动重试；应到 MT5 中核对实际挂单和本地记录。已有持仓的风险不包含在本次预算内。

开发测试只使用 **0.01 手**的请求。自动化测试模拟 `order_send()`；
启动界面不会自动下单，只有完成预览并点击“确认发送”后才会提交真实挂单。

## 控制面板

页面可见时，持仓与浮盈亏按底栏“持仓”间隔自动更新（默认 5 秒），挂单按“订单”间隔更新（默认 30 秒）；均可点击底栏修改。自动读取保留列表和已勾选目标，不会反复清空。切换操作范围或账户时重新读取对应数据。

在左侧进入“控制面板”，选择“仅当前品种”（默认 `XAUUSDc`）或“整个账户 · 所有品种”。
页面显示所选范围内的持仓和挂单，并提供四个独立操作：

- **全部平仓**：预览持仓 Ticket、方向、手数和开仓价，确认后逐笔按当前市价发送反向交易请求。可设置最大偏差点数，默认 50 点。平仓不会撤销挂单；挂单之后仍可能成交。
- **删除所有挂单**：预览挂单 Ticket、类型和手数，确认后逐笔撤销。若挂单在撤销前成交，撤单可能失败，已形成的持仓不会因此消失。
- **一键推保本**：默认按**每笔持仓预计锁定 1 USD 毛利润**计算新止损；USC 账户中即 100 USC。实际价格由 MT5 的 `order_calc_profit` 按该笔品种、方向和手数反求，预览逐笔显示原止损、新止损和预计金额。已有更有利的止损不会被放宽；若任一持仓当前浮盈不足，整批预览会提示对应 Ticket 并停止。手续费、隔夜费、跳空和成交偏差可能使最终净利不同。
- **批量设置止盈／止损**：先在“选择持仓”列表勾选目标（支持全选），填写一个或两个统一绝对价；留空的一侧保持原值。勾选的持仓若包含多个品种，会拒绝把同一价格套用于不同品种。预览列出每笔修改前后的价格，并支持再次取消勾选；已有相同保护价的持仓明确标为已满足目标，无需修改。推保本也使用勾选的持仓；全部平仓与删除所有挂单仍按操作范围执行。

多笔保护价修改在后台逐笔发送，默认每笔间隔 **2 秒**，界面显示进度。发送频率限制由券商决定，间隔不保证所有服务器都接受；若收到 `10024`（请求过于频繁），显示已完成数量并停止，不自动重试。稍后刷新，重新勾选未完成持仓并预览确认即可继续。执行期间不能并发提交其他交易操作；切换账户、重新连接或退出程序会停止尚未发送的修改，正在发送的那一笔需核对 MT5 实际结果。

四项操作均需先预览，再点击确认；确认时重新核对 USC 账户、目标和报价。持仓止盈止损使用 MT5 的 [`TRADE_ACTION_SLTP`](https://www.mql5.com/en/docs/constants/tradingconstants/enum_trade_request_actions) 请求，保留未修改的一侧，并核对品种价格步进、最小止损距离和冻结距离。执行结果保存在 `state/controls/`。
失败或状态不确定时停止剩余目标，不自动重试。操作后以 MT5 客户端中的实际持仓和挂单为准。
开发测试中的平仓和保护价修改只使用模拟的 **0.01 手**持仓，测试不会调用真实账户的 `order_send()`。
