# MT5 黄金交易工作台

基于 PySide6（Qt）的本地 Python 图形界面，读取当前已登录的 MetaTrader 5 账户、
`XAUUSDc` 报价、持仓和挂单，并测算固定止损下的限价单分档方案。工作台分为
“总览看板”“交易概览”“行情日志”“下单管理”“控制面板”五页；首页提供 M5 K 线、账户关键指标和
近 30 日已实现净损益。测算后可在预览窗口确认并发送 LIMIT 挂单。

## 启动

在 Windows PowerShell 中运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m mt5_workbench
```

界面使用项目依赖清单中固定版本的 PySide6；启动和安装依赖均使用该虚拟环境中的 Python。
原有的 `.\.venv\Scripts\python.exe .\gui.py` 启动命令暂时保留为兼容入口。
如有多个 MT5 客户端，可加 `--terminal "C:\Program Files\MetaTrader 5\terminal64.exe"`。
工作台只接受账户币种为 `USC` 的美分账户，并按 **100 USC = 1 USD** 计算。
连接时和运行中都会重新读取 MT5 账户；若币种不是 `USC`，工作台会弹出锁定警告，
停止看板读取、仓位测算和交易操作。切换回 `USC` 账户后，可在警告窗口点击“重新检查账户”。
界面有日间、夜间两种主题；首次启动随 Windows 应用主题，之后记住右上角切换的选择。
侧栏固定为五个工作区，当前仅面向 `XAUUSDc`，不提供切换交易品种的入口。
最小窗口为 **1200 × 800**，页面在窗口化时可纵向滚动；支持全屏与 2K 显示，
可点击右上角“全屏”或按 `F11`，按 `Esc` 退出。界面规则见 [界面设计规范](docs/UI_DESIGN.md)。
侧栏和操作按钮使用统一图标；深浅主题自动切换对应配色。图表由 Qt 控件绘制，
无需额外安装网页浏览器组件。
图标的 SVG 源文件与多尺寸 PNG 位于 [界面资源目录](src/mt5_workbench/ui/resources/icons/README.md)。

## 工程目录

桌面应用代码位于 `src/mt5_workbench/`，按职责划分：

| 目录 | 内容 |
| --- | --- |
| `domain/` | USC 账户规则、仓位优化计算和日志数据模型 |
| `services/` | 看板数据、交易概览、日志持仓同步、挂单发送和账户控制 |
| `infrastructure/` | MT5 行情接口、本地 SQLite 日志及外部依赖适配 |
| `ui/` | Qt 主窗口、主题、页面和图表控件 |

`tests/` 是离线测试；`docs/` 保存架构说明。项目根目录只保留元数据、资源和兼容启动脚本。
代码分层和后续整理阶段见 [架构计划](docs/ARCHITECTURE_PLAN.md)。

## 本地数据与公开代码

程序通过本机 MT5 客户端读取账户、行情与订单，不在源码中保存账户密码。实际账户号、
交易执行记录、行情日志帖子与图片以及主题偏好保存在本机的 `state/`；该目录被 Git 忽略。
测试使用虚构账户。公开分享代码时，请勿手动添加账户截图、终端导出的报告或本地数据库。

## 总览看板

首页从 MT5 读取 `XAUUSDc` 实时报价、昨日收盘价和最近 72 根 M5 K 线，
展示 Bid/Ask、点差、较昨收变动、账户净值、余额、浮动盈亏、可用保证金、
保证金水平以及当前持仓和挂单。行情每秒刷新，持仓/挂单每 5 秒刷新，
图表与历史统计每 60 秒刷新。

近 30 日柱状图统计**已实现净损益**，单位始终是账户币种（本账户为 USC），
包含交易成交的利润、佣金、隔夜费及手续费；不含当前浮动盈亏和出入金。
历史读取失败会显示不可用，不会把缺失数据当作零。K 线包含正在形成的当前一根，
用空心柱区分；图表时间轴标注为 UTC。

## 交易概览

左侧“交易概览”是只读看板，分别读取 MT5 的当前挂单、当前持仓、历史订单和
实际成交。可切换 `XAUUSDc` 与整个账户，以及近 7 / 30 / 90 个本地日；
页面可见时每 30 秒刷新，也可手动刷新。切换账户时会清空上一个账户的记录。

顶部展示当前余额、当前净值，以及所选期间**全账户**的累计交易净现金流折线。
鼠标悬浮到日期可查看当日净额、累计净额和回撤。最大回撤与当前距峰值按每日
累计现金流计算，单位为账户币种；期间起点设为零。这条曲线排除出入金和
未平仓浮盈亏，**不是历史余额或权益曲线**，其回撤也不是 MT5 内置报告的
账户权益回撤。选择 `XAUUSDc` 只影响下面的订单/成交明细与相关指标，
账户曲线始终统计整个账户。

看板显示挂单数、持仓数、期间历史订单数、实际成交笔数、交易净现金流与挂单
止损覆盖情况。每日成交图按 BUY / SELL **成交方向**展示；全账户视图改用
成交笔数，避免把不同品种的手数相加。历史订单状态图只统计已结束的历史订单。
三个明细表分别列出当前有效挂单、最近 100 笔 BUY / SELL 实际成交及最近
100 笔历史订单；选中一行可查看时间、价格、止损止盈或成交资金分项。
顶部统计仍覆盖所选期间的全部返回记录，不受明细表 100 行上限影响。

金额直接使用账户币种（本账户为 USC，**100 USC = 1 USD**）。
“交易净现金流”汇总成交利润、隔夜费、佣金和手续费，并纳入能够关联的独立
佣金分录；它不等同于已完整平仓交易的盈亏，逐笔成交现金流也不应当作一笔
完整交易的利润。BUY / SELL 成交方向也不等同于当前持仓方向。MT5 某类历史
读取失败时，该类指标显示“—”和错误信息，不把缺失记录算作零。
此页不会调用 `order_send()`。

[MT5 Python 接口](https://www.mql5.com/en/docs/python_metatrader5)提供原始订单与成交记录，
但没有直接返回终端内置交易报告的函数。终端可[手动导出 HTML/PDF 报告](https://www.metatrader5.com/zh/terminal/help/trading_advanced/history_report)；
本页为保证自动更新，直接依据成交记录计算。

## 行情日志

在“行情日志”中写短帖，可添加本地图片、关联多笔当前 `XAUUSDc` 持仓。帖子按账户隔离，
每页 10 条；持仓结束后从 MT5 历史成交中同步最终净额。记录轨迹可按年份展示
当前账户的发帖热力图；顶部统计仍按累计、过去 30 天和过去 365 天计算。数据库与图片保存在程序旁的 `state/journal/`，不会调用
`order_send()`。完整使用和数据口径见 [行情日志说明](docs/JOURNAL.md)。

## 下单管理（限价单）

风险预算、目标入场价、误差度和统一止损价初始为空，需要自行填写；预算使用比例默认
**95%**、开仓档数默认 **3**、加权模式的每档权重默认 `1,2,3`。
统一止盈价可选：留空表示不设置止盈，填写后所有档位使用同一止盈价。

输入目标价 **4220**、误差度 **1**，程序自动生成 **4219～4221** 的入场区间；
三档时价格为 **4219、4220、4221**。止损必须在整个区间之外。

填写示例：风险预算 **30 USD**、预算使用比例 **95%**，因此实际风险上限为
**28.50 USD**；目标价 **4205**、误差度 **5**，生成区间 **4200～4210**，统一止损 **4220**，
三档等距价格 **4200、4205、4210**。止损在区间上方时按 SELL 测算，
在区间下方时按 BUY 测算。支持四种模式：

- **加权分配**：输入 `1,2,3` 等权重，按比例分配每档的美元风险。
- **等风险**：每档承担近似相同的美元风险。
- **覆盖区间、总手数优先**：每档至少有券商最小手数，剩余预算优先放到离止损最近的价格。
- **单点总手数最大**：仅在离止损最近的区间端点配置手数。

示例按 `1,2,3` 加权，当前合约参数下约为 **0.23 / 0.64 / 1.43 手**，
合计 **2.30 手**，三档都成交并触及止损时估算风险 **28.50 USD**，
相对原预算保留 **1.50 USD**。
各档手数会按 MT5 的最小手数、步进与最大手数约束处理。

“预算使用比例”与“每档风险权重”不同：前者先决定整次测算可使用的上限
（`风险预算 × 百分比`，允许 0～100% 中大于 0 的数）；后者只在加权模式中
分配这个上限。四种模式的结果都会遵守相同的有效上限。界面“原预算剩余”
显示原始预算减去估算风险，包含预留比例与手数步进留下的余额。

风险约定为 `1 手 × 价格波动 1 = 1 USD`。当前账户币种是 USC，
按 `100 USC = 1 USD` 换算；计算时也会调用 MT5 的 `order_calc_profit()` 核对。
如果合约实际风险与约定明显不符，会拒绝给出配置。

计算结果只表示**所有列出的档位都成交，随后在指定价格止损**时的估算亏损。
滑点、跳空、手续费、隔夜费和保证金限制未计入；界面只提示 LIMIT 候选或不可作为 LIMIT，
当前报价不满足 LIMIT 条件时禁用发送预览。
可用“复制配置”将结果复制到剪贴板。

## 发送 LIMIT 挂单

计算结果后点击“预览并发送 LIMIT”。程序重新读取账户、品种和报价，核对当前测算结果、
预算上限、止盈方向、价格步进、最小手数、最小挂单距离及现有相同挂单；仅当所有档位均可作为
BUY LIMIT 或 SELL LIMIT，且全部通过 MT5 `order_check()` 时才会显示发送预览。
预览列出账户、生成区间、实时报价、每笔入场价、手数、统一止损、统一止盈和估算风险。核对后点击
“确认发送”才会逐笔调用 `order_send()`；点击“取消”则关闭预览且不发送。
挂单使用 GTC（长期有效）。填写止盈价时，程序会核对其方向、品种支持情况和最小距离，
并将它写入每笔挂单；留空则在预览中显示“—”。
真实发送前须在 MT5 客户端启用“算法交易”；未启用时界面会阻止发送。

程序在发送前建立本地记录，逐笔保存返回的订单号与状态到 `state/executions/`，
同一配置重复发送会被阻止。若中途失败或返回状态不确定，程序停止后续挂单，
不会自动重试；应到 MT5 中核对实际挂单和本地记录。已有持仓的风险不包含在本次预算内。

开发测试只使用 **0.01 手**的请求。自动化测试模拟 `order_send()`；
启动界面不会自动下单，只有完成预览并点击“确认发送”后才会提交真实挂单。

## 控制面板

在左侧进入“控制面板”，选择“仅当前品种”（默认 `XAUUSDc`）或“整个账户 · 所有品种”。
页面显示所选范围内的持仓和挂单，并提供两个独立操作：

- **全部平仓**：预览持仓 Ticket、方向、手数和开仓价，确认后逐笔按当前市价发送反向交易请求。可设置最大偏差点数，默认 50 点。平仓不会撤销挂单；挂单之后仍可能成交。
- **删除所有挂单**：预览挂单 Ticket、类型和手数，确认后逐笔撤销。若挂单在撤销前成交，撤单可能失败，已形成的持仓不会因此消失。

两项操作均在确认前重新核对账户和目标；执行结果保存在 `state/controls/`。
失败或状态不确定时停止剩余目标，不自动重试。操作后以 MT5 客户端中的实际持仓和挂单为准。
开发测试中的平仓请求只使用模拟的 **0.01 手**持仓，测试不会调用真实账户的 `order_send()`。

```powershell

```
