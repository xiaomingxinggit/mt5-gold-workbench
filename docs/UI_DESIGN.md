# MT5 黄金交易工作台 · Qt Quick 界面规范

## 技术与页面

默认入口 `python -m mt5_workbench` 加载 [`ui/qml/App.qml`](../src/mt5_workbench/ui/qml/App.qml)。六个页面均使用 PySide6 6.11.2 的 Qt Quick/QML、Qt Quick Controls FluentWinUI3 样式及原生 Canvas 绘图，不使用 HTML 或 WebEngine。Python 的 MT5 服务仍位于 `domain/`、`services/` 和 `infrastructure/`。旧版 QWidget 文件暂作兼容与回归参考，不再作为默认入口。

导航顺序固定为总览看板、交易概览、行情日志、下单管理、控制面板、实验功能。当前交易品种固定为 `XAUUSDc`。工作台仅允许 USC 美分账户；不符合条件时在内容区显示锁定层，顶部保留重新连接入口。

## 视觉系统

当前界面的颜色 token 统一放在 [`ui/qml/Theme.qml`](../src/mt5_workbench/ui/qml/Theme.qml)。背景、表面、边框、正文、次级文字、强调色、盈亏和警示色均使用语义属性；两种主题保持相同的信息层级和控件位置。`ui/theme.py` 负责读取与保存主题偏好，旧版 QWidget 的调色板也保留在那里。图表网格始终弱于数据线；收益、亏损与操作风险除颜色外还要有数值、符号或文字。

全局字体为 Microsoft YaHei UI，系统未安装时由 Qt 回退。文本统一用像素字号：辅助 11–12、正文 13–14、分区标题 16–18、页面标题 28、关键数值 22–28。标签和正文优先常规字重，导航选中项、标题和关键数值使用 DemiBold。手数、价格、资金和时间明确标注单位或数据口径；缺失值用“—”，加载中与过期报价必须有文字状态。USC 账户中 **100 USC = 1 USD**，美元风险要显式标为 USD。

界面不使用品牌 LOGO。操作图标的 SVG 源文件位于 [`ui/resources/icons/svg/`](../src/mt5_workbench/ui/resources/icons/README.md)，按明暗主题加载；图标与按钮文字配对使用。卡片采用表面色、细边框和圆角，不叠加厚重阴影。滚动条只在内容超出时出现。

## 尺寸与布局

窗口最小 **1200 × 800**，默认 **1440 × 900**；顶部栏、侧栏、内容区和底部状态栏之间留 10–14 px 间距。侧栏在紧凑宽度下为 198 px，宽窗口为 222 px。六页内容区统一有 24 px 内边距，卡片之间留 16–18 px，卡片内边距以 18–22 px 为主。

表单和图表用 `GridLayout`、`RowLayout` 与 `ColumnLayout` 根据可用宽度重排：窄窗口改为单列，宽窗口显示双列；各页内容可以纵向滚动，不允许重要按钮被横向裁切。交易确认弹窗在最小窗口下仍保留可见的取消与确认按钮。全屏和 2K 窗口不能无限拉长文字行或让图表丢失刻度。`F11` 切换全屏；`Esc` 可退出全屏或取消当前确认弹窗。

年度日志热力图卡片与上方统计卡片共用左右边界；标题靠左，年份筛选靠右。月份、方块和图例使用同一网格宽度，并在卡片内居中；按年份生成 53 或 54 列周格。并排的分析卡片顶端对齐、同一行高度一致。

日志列表按北京时间（UTC+8）的日期分组，用左侧细线和节点连接帖子；日期标题与帖子卡片左边缘对齐，轨道区宽 16 px，与卡片间距 12 px，卡片内边距 22 px。帖子内显示时分，不重复账户编号；账户范围由页面顶部标识。回复放在所属帖子下方，每条最多 2,100 字、4 张图片，每张不超过 8 MiB，可只发图片。帖子、回复和草稿的图片都可点击预览；预览支持切换、放大、拖动和 Esc 关闭，Esc 优先关闭预览。切换账户会关闭预览并清理未发布草稿。

## 页面结构

- 总览看板：账户身份与连接状态、黄金 Bid/Ask 和点差、账户关键指标、M5 K 线、近 30 日已实现净损益及当前持仓/挂单。图表与历史统计每 60 秒刷新；底栏可分别设置报价、持仓和挂单的刷新间隔，默认 1、5、30 秒，范围为 1–3600 秒。
- 交易概览：范围与天数筛选、全账户交易现金流与按日回撤折线、每日成交及历史订单状态、成交与订单摘要、最近记录表。现金流曲线不等同于账户余额或权益曲线；缺失历史不得显示为零。历史读取在后台完成，页面切换立即反馈。
- 行情日志：账户范围、汇总指标、可切换年份的发帖热力图、日期时间轴和分页、本地图片及关联持仓。日期、活跃天数与热力图统一按北京时间计算。帖子下方支持文字和图片回复；两种编辑框均支持 Ctrl+V 粘贴剪贴板图片，也可点击“粘贴图片”。未发布草稿在读取刷新后保留，持仓关闭后显示最终结果；删除帖子会一并删除回复和关联图片。
- 下单管理：页头下设“基础下单 / 高级下单”两个 Tab，默认基础模式。基础模式左侧为买入/卖出限价切换、限价、手数及可选止损/止盈，右侧为实时报价、账户和下单说明；默认手数 0.01，其他价格留空。内容宽度不足 1100 时卡片上下排列。高级模式保留目标价与误差度、风险预算、预算使用比例、止损、可选止盈和分档方式；预算、目标价、误差度、止损默认留空，使用比例默认 95%，档数默认 3，权重默认 `1,2,3`。两种模式都只发送 LIMIT，发送前预览确认；切换 Tab 使旧预览及测算失效。
- 控制面板：当前品种或全账户范围、持仓和挂单目标、全部平仓、删除挂单、一键推保本及批量设置止盈／止损四项独立预览。推保本默认按每笔持仓锁定约 1 USD 毛利润计算；批量价格留空的一侧保持原值，混合品种不得共用统一绝对价。目标读取在后台完成；范围变更时旧目标的按钮立即禁用。
- 实验功能：M1 EMA 7/14/30/60、报价新鲜度、允许偏差和会话记录。页面只读；均线聚拢不解释为反转概率。

## 响应与交易确认

[`ui/qml_bridge.py`](../src/mt5_workbench/ui/qml_bridge.py) 按页面分区发布变化，报价更新不会重建六页状态。耗时的历史、图表、日志和控制目标读取在后台执行；旧账户或旧筛选条件的迟到结果被丢弃。账户检查和短行情读取仍需观察真实终端下的耗时。界面必须显示加载、失败和报价过期状态。

[`ui/qml_trade_bridge.py`](../src/mt5_workbench/ui/qml_trade_bridge.py) 是当前界面唯一的写操作入口。LIMIT 下单、全部平仓、撤单及持仓保护价修改都先预览账户、范围、价格、手数和目标，再由显式确认按钮执行。确认时重新核对 USC 账户、订单或持仓目标与报价；取消、页面刷新、主题切换和只读测试不得调用真实 `order_send()`。失败后停止后续目标，不自动重试。

## 验证

离线回归覆盖六页 QML 加载、深浅主题状态、最小窗口、账户切换、慢历史与控制面板读取、0.01 手模拟下单的预览与确认。视觉检查仍须在 Windows 实屏的 1200 × 800、1440 × 900、2560 × 1440 尺寸下逐页检查两种主题，特别关注中文渲染、表格、空状态、长文本、滚动和确认弹窗。
