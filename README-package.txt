MT5 黄金交易工作台（Windows x64）

版本：0.2.2（单文件 EXE）

1. 将 MT5Workbench.exe 放到任意合适的文件夹；如果下载的是压缩包，请先解压，不要直接在压缩包内运行。
2. 先启动并登录 MetaTrader 5 客户端。
3. 双击 MT5Workbench.exe 启动。本包已包含 Python、MetaTrader5 Python 包、NumPy 和图形界面所需运行库，无需再安装 Python 包。

侧栏“行情监测”提供 XAUUSDc 的 M1 EMA 7 / 14 / 30 / 60 只读监听；“实验功能”单独保留为“暂未开放”页面。行情监测不会自动下单。

如果电脑上有多个 MT5 客户端，可在 PowerShell 中运行：
  .\MT5Workbench.exe --terminal "C:\Program Files\MetaTrader 5\terminal64.exe"

侧栏“系统配置”可查看实时系统时间，设置全局显示时区（默认北京时间 UTC+8）、报价／持仓／订单刷新间隔和界面主题，并查看 UTF-8 编码、运行环境及本地数据路径。未连接 MT5 时仍可使用。时区设置仅调整工作台显示；日志热力图与活跃天数仍按北京时间计算。

软件首次运行会自动创建当前 Windows 用户的数据目录：
  %LOCALAPPDATA%\MT5Workbench\state
例如 C:\Users\你的用户名\AppData\Local\MT5Workbench\state。
该目录集中保存交易执行记录（executions、controls）、行情日志帖子与图片（journal）、界面主题、刷新间隔及系统时区设置。以后移动或替换 EXE 无需搬动数据。“系统配置 → 连接与本地数据”可查看实际路径，并点击“打开数据目录”。备份时复制整个数据目录。

本发布包不含个人数据。全新用户无需准备任何文件夹。老用户首次在原位置启动新版时，会自动复制 EXE 旁的旧 state 数据到用户数据目录；源码启动时迁移项目内的旧 state。原文件保留作备份，已有的新版日志和设置不会被旧数据覆盖。建议先关闭旧版，再升级启动新版，完成迁移后可自由移动 EXE。

“系统配置 → 版本与更新”显示当前版本、最新正式版本、检查时间和发布说明。启动后自动检查 GitHub Release，每 6 小时复查，也可点击“检查更新”。需要联网访问 GitHub；断网只会显示检查失败，不影响本地使用。普通代码提交和预发布不会提示更新。发现新版后，点击“下载新版 EXE”通过浏览器下载，关闭工作台后替换原 EXE；日志和设置会继续使用用户数据目录。程序不会自动覆盖正在运行的 EXE。

程序不会自动下单。发单、平仓或撤单均需在界面中预览并确认。实际交易还要求 MT5 客户端允许算法交易。
